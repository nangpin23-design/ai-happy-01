# Make the AI judge happy — ai-happy-01

Entry for [make.fun](https://make.fun/bounty/ai-happy-01)

`main.py` copies `entry.png` (a joyful orange tabby kitten laughing in a
sunny wildflower meadow at golden hour, surrounded by butterflies) to
`/output/entry.png`.
Deterministic, no network, no randomness — both runs write the same bytes.
Image: PNG, 800x800, under 1 MiB.

Run locally:

```
python3 main.py
ls -lh /output/entry.png
```
